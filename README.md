# Honorine CalcUtils

A simple Python utility package created as part of a Software Engineering and Python Development lab.

## Features

* Add two numbers
* Multiply two numbers
* Calculate the average of a sequence of numbers

## Installation

```bash
pip install honorine-calcutils
```

## Usage

```python
from honorine_calcutils import add, multiply, average

print(add(10, 25))
print(multiply(5, 4))
print(average([10, 20, 30, 40]))
```

Output:

```text
35
20
25.0
```
